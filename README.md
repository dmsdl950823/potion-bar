# 🧪 포션 (Potion)

> 집에 있는 술, 오늘은 맛있게.

Potion은 퇴근 후 집에서 술을 즐기는 30~40대 직장인을 위한 한국어 홈술 추천 서비스입니다. 보유한 술과 집에 있는 재료를 고르면 지금 만들 수 있는 칵테일, 부족한 재료 1~2개로 만들 수 있는 조합, 그리고 어울리는 안주를 추천합니다.

전문 바텐딩 지식이나 낯선 해외 재료를 전제로 하지 않습니다. 편의점·마트에서 쉽게 구할 수 있는 재료와 1잔 기준의 명확한 비율로, 집에서 빠르게 한 잔을 완성하도록 돕습니다.

## 어떻게 동작하나요?

```text
보유 술 선택
  → 선택 사항: 믹서·부재료 선택
  → 제조 가능 여부와 부족 재료 수를 기준으로 레시피 추천
  → 맛·도수·상황으로 결과 필터링
  → 1잔 레시피, 대체 재료, 안주 페어링 확인
  → 마음에 드는 레시피 즐겨찾기
```

예를 들어 위스키와 탄산수를 선택하면, Potion은 퇴근 후 마시기 좋은 하이볼을 우선 제안합니다. 레시피 카드에서 예상 도수, 당도, 소요 시간, 난이도와 필요한 추가 재료를 비교할 수 있고, 상세 화면에서 1잔 비율과 어울리는 안주를 확인합니다.

## MVP 범위

포함하는 기능은 다음과 같습니다.

- 보유 술·부재료 기반 레시피 탐색
- `바로 만들 수 있음`과 `재료 1~2개 추가 필요` 구분
- 6대 기주, 와인, 전통주·막걸리, 사케·쇼츄·우메슈 조합
- 당도, 알코올 여부·완성 도수, 주종, 분위기·상황 필터
- 1잔 기준 재료·도량형, 제조 단계, 맛 스펙트럼, 난이도
- 편의점·마트 대체 재료와 편의점·배달·간단 조리 안주 페어링
- 기기 내 즐겨찾기

로그인과 술장 동기화, 라벨 스캔, 위치 기반 재고·구매, 사용자 레시피 등록, 개인화 AI 추천은 이후 단계에서 다룹니다.

## 데이터 원칙

Potion은 외부 API와 공식 데이터 다운로드를 우선 사용합니다. 수집한 원문은 보존하고, 한국어 번역·정규화·맛 태그·안주 페어링 결과는 원문과 분리해 검수 상태와 출처를 추적합니다.

데이터는 Supabase Local의 PostgreSQL에서 검증한 뒤 같은 migration을 Supabase Cloud에 적용하는 방식으로 운영할 예정입니다. 외부 데이터를 수집하기 전에 라이선스, 상업 이용, 재배포, 이미지 사용 조건을 확인합니다.
