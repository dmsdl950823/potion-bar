## 1. 제품 한 줄 정의

**Potion은 퇴근 후 집에서 술을 즐기는 30~40대 직장인이 보유한 술과 쉽게 구할 수 있는 재료를 선택하면, 지금 만들 수 있는 한 잔과 어울리는 안주를 빠르게 추천하는 한국어 홈술 서비스다.**

핵심 약속은 “오늘 가진 것으로, 실패 없이, 5분 안에 한 잔”이다.

## 2. 사용자와 해결할 문제

### 핵심 사용자 — 확정

- 30~40대 직장인
- 외식 술값과 이동 시간을 아끼며 집에서 혼술·반주·가벼운 모임을 즐기는 사람
- 전문 바텐딩 지식보다 쉬운 조합, 국내 구매 가능 재료, 맛과 도수 예측을 원하는 사람
- 위스키·와인·전통주 등 집에 남아 있는 술을 다른 방식으로 활용하고 싶은 사람

### 주요 사용 상황

1. 퇴근 후: 집에 있는 위스키와 탄산수로 가볍게 한 잔 마시고 싶다.
2. 주말 반주: 와인이나 막걸리에 어울리는 간단한 안주를 찾고 싶다.
3. 홈파티: 보유 술로 여러 사람이 무난하게 즐길 조합을 고르고 싶다.
4. 남은 술 활용: 취향에 맞지 않거나 개봉 후 남은 술을 맛있게 소비하고 싶다.

### 해결할 문제

- 무엇을 만들 수 있는지 몰라 보유한 술을 활용하지 못한다.
- 해외 레시피는 재료명·도량형·구매처가 한국 사용자에게 낯설다.
- 레시피를 찾은 뒤에도 맛, 완성 도수, 난이도를 예상하기 어렵다.
- 술과 안주를 별도로 검색해야 하고 추천 이유가 불분명하다.

## 3. 시장 인사이트와 제품 적용

[주류 소비 트렌드 분석](https://share.gemini.google/UWuF4YzWlLFT)에 따르면 국내 주류 소비는 전체 출고량 감소 속에서 외식보다 가정용 소비가 강해지고, 양보다 취향·품질을 중시하는 방향으로 이동하고 있다. 고물가, 외식 주류 가격 상승, 회식 감소가 홈술을 지지하며 저도수·무알코올·제로슈거와 하이볼 같은 믹솔로지 수요도 커지고 있다.

이를 Potion에 다음과 같이 적용한다.

| 관찰 | 제품 결정 |
|---|---|
| 가정용 주류 소비의 정착 | 홈 화면의 첫 행동을 `보유 술로 찾기`로 둔다. |
| 외식비 부담과 편의점의 접근성 | 편의점·마트에서 살 수 있는 부족 재료와 예상 추가 비용을 보여준다. |
| 양보다 취향 중심 소비 | 단순 인기순보다 맛·도수·상황 기반 탐색을 우선한다. |
| 저도수·절주 관심 증가 | 완성 예상 도수, 당도, 저도수·무알코올 필터를 제공한다. |
| 하이볼·RTD·한국형 믹솔로지 성장 | 하이볼, 와인 활용, 막걸리·전통주, 사케·쇼츄·우메슈 조합을 독립 컬렉션으로 제공한다. |
| 혼술·반주 증가 | 1잔 기준 레시피와 편의점·배달·간단 조리 안주를 함께 추천한다. |

> 위 공유 문서는 방향 탐색을 위한 2차 자료다. 문서에 포함된 출고량·시장 비중·성장률을 외부 콘텐츠나 투자 자료에 인용할 때는 국세청 TASIS, aT FIS, 통계청 등 원출처와 산출 방식을 다시 검증한다.

## 4. 경쟁 환경과 차별화

[칵테일 서비스 조사](https://share.gemini.google/SkHpoG6qL06r)를 기준으로 경쟁 서비스를 다음 네 유형으로 본다.

| 유형·예시                                    | 강점                  | Potion이 집중할 빈틈                      |
| ---------------------------------------- | ------------------- | ----------------------------------- |
| 전문 백과사전 — Difford's Guide, Liquor.com    | 방대한 레시피, 역사와 전문 정보  | 한국어, 국내 유통 재료, 빠른 의사결정              |
| 보유 재료·홈바 — My Bar, Mixel, Cocktail Party | 재고 기반 제조 가능 레시피     | 30~40대 직장인의 퇴근 후 상황, 안주까지 한 번에 추천   |
| 국내 레시피·홈바 — BarShelf, 칵테일 위키, Jigger     | 한국어, 술장·기록·AI 추천    | 편의점 부족 재료, 예상 맛·도수, 추천 근거를 한 화면에 제공 |
| 커머스 — 데일리샷 등                             | 상품 정보, 가격·재고, 구매 연결 | 구매 전환보다 이미 가진 술의 활용과 레시피 완성에 집중     |

Potion의 초기 차별점은 다음 순서로 평가한다.

1. **국내 재료 현실성:** 편의점·마트에서 구할 수 있는 대체 재료까지 안내한다.
2. **즉시 제조 가능성:** `바로 만들 수 있음`과 `1~2개만 더 사면 됨`을 구분한다.
3. **선택 확신:** 예상 맛, 완성 도수, 소요 시간, 난이도, 추천 이유를 먼저 보여준다.
4. **한 잔 완성 경험:** 레시피와 안주를 하나의 결과로 묶는다.
5. **한국형 범위:** 클래식 기주뿐 아니라 와인, 전통주·막걸리, 일본술 조합을 다룬다.

AI 추천, 라벨 스캔, 방대한 레시피 수 자체는 경쟁사가 이미 제공하므로 초기 핵심 차별점으로 삼지 않는다.

## 5. MVP 사용자 여정 — 확정

```text
홈
  → 보유 술 선택(큰 분류 → 세부 종류/제품)
  → 선택 사항: 집에 있는 믹서·부재료 선택
  → 결과
      ├─ 지금 바로 만들 수 있음
      └─ 재료 1~2개를 더 사면 만들 수 있음
  → 맛·도수·상황 필터 또는 정렬
  → 칵테일 선택
  → 레시피·대체 재료·안주 상세
  → 즐겨찾기
```

### 핵심 화면

1. **홈/탐색:** 보유 술로 찾기, 퇴근 후 한 잔, 가벼운 반주, 주말 홈파티, 저도수 컬렉션
2. **보유 재료 선택:** 6대 기주·와인·한국술·일본술의 큰 분류를 먼저 보여주고 세부 종류를 펼친다. 믹서·부재료 선택은 건너뛸 수 있다.
3. **추천 결과:** 제조 가능 여부, 부족 재료 수, 맛, 예상 도수, 시간, 난이도를 카드에서 비교한다.
4. **레시피 상세:** 1잔 기준 재료와 비율, 단계별 제조법, 대체 재료, 주의사항, 안주 추천과 추천 이유를 제공한다.
5. **즐겨찾기:** MVP에서는 기기 내 저장으로 제공하고, 계정 동기화와 개인 술장 DB는 P2에서 확장한다.

### 정렬 원칙

기본 점수는 `제조 가능성 > 부족 재료 수 > 취향 적합도 > 난이도 > 콘텐츠 품질` 순으로 계산한다. 인기순만으로 기본 결과를 정렬하지 않는다.

## 6. MVP 범위 — 확정

### 포함

- 주종
  - 6대 기주: 진, 보드카, 럼, 데킬라, 위스키, 브랜디
  - 와인: 레드, 화이트, 스파클링
  - 한국술: 전통주, 막걸리
  - 일본술: 사케, 쇼츄, 우메슈
- 레시피: 클래식 칵테일, 하이볼, 와인 활용, K-믹솔로지, 일본식 믹스
- 탐색: 보유 술·부재료, 알코올 여부, 완성 도수, 주종, 당도, 분위기·상황
- 제조 가능 상태: 즉시 가능 / 재료 1~2개 부족 / 탐색 결과 제외
- 구매 맥락: 편의점·마트에서 구하기 쉬운 재료 여부와 대체재
- 상세 정보: 1잔 기준 재료·도량형, 제조 단계, 맛 스펙트럼, 예상 도수, 시간, 난이도, 안주
- 기기 내 즐겨찾기
- 모바일 우선 반응형 웹

### 제외

- 로그인, 여러 기기 동기화, 영구적인 개인 술장
- 라벨·바코드·영수증 스캔
- 위치 기반 매장 재고·실시간 가격·주류 구매 중개
- 사용자 레시피 등록, 리뷰, 커뮤니티
- 행동 기반 개인화·대화형 AI 바텐더
- 잔 추천: 데이터 필드는 미리 준비하되 화면 노출은 MVP 이후 검토
- 네이티브 앱

## 7. 콘텐츠 및 분류 정책 — P0 기준

### 한국어 표기와 도량형

- 대표 이름은 통용되는 한국어명, 보조 이름은 원어명으로 저장한다. 예: `모히토 (Mojito)`.
- 재료는 표준명과 별칭을 분리한다. 제품 브랜드는 표준 재료의 예시로 취급한다.
- 액체는 `ml`, 소량은 `dash`, 고형물은 `개·조각·티스푼`을 사용한다.
- 원문 oz는 저장하되 화면에서는 ml로 환산하고 실용 단위로 반올림한다.
- 모든 레시피의 기본 제공량은 1잔이며 배수 조절 시 총량을 함께 표시한다.

### 맛 스펙트럼

각 항목을 0~5 정수로 저장하고, 사용자 화면에는 낮음·보통·높음과 그래프로 표시한다.

- 당도, 산미, 쓴맛, 바디감, 탄산감
- 데이터가 없으면 추정값임을 표시하고 검수 상태를 별도로 저장한다.

### 완성 도수

- 레시피 재료의 알코올량과 희석 전 총량으로 예상 ABV를 계산한다.
- 구간: 무알코올 0.0% / 논알코올 0.1~1.0% 미만 / 낮음 1~8% 미만 / 보통 8~20% 미만 / 높음 20% 이상
- 얼음 희석, 제품별 도수 차이로 실제 값이 달라질 수 있다는 문구를 함께 표시한다.

### 난이도

- 쉬움: 3개 이하 재료, 전용 도구 없음, 5분 이내
- 보통: 4~5개 재료 또는 셰이킹·간단 가니시 필요
- 어려움: 6개 이상 재료, 블렌딩·레이어링·사전 준비 또는 정밀한 기법 필요

### 상황·가성비·구매 태그

- 상황: 퇴근 후, 혼술, 반주, 홈파티, 브런치, 디저트, 계절 한 잔
- 취향: 상큼한, 달콤한, 드라이한, 쌉싸름한, 청량한, 묵직한
- 절주: 저도수, 무알코올·논알코올, 무가당 재료 활용
- 접근성: 편의점 완성, 마트 완성, 재료 3개 이하, 5분 완성, 남은 술 활용
- 가성비는 가격 단정 대신 `추가 구매 0개`, `1개`, `2개`와 구매처 접근성으로 표현한다.

### 안주 분류와 페어링

- 구매 방식: 편의점, 배달, 간단 조리
- 음식 특성: 짠맛, 단맛, 매운맛, 기름짐, 산미, 감칠맛, 담백함
- 추천은 `보완`(상반된 맛으로 균형), `강화`(공통 향미 연결), `정리`(탄산·산미로 입안을 정돈) 중 한 가지 이유를 반드시 제공한다.
- 알레르기 유발 가능 재료와 식이 태그는 확인 가능한 경우 표시하며 의료적 안전을 보장하는 표현은 쓰지 않는다.

### 연령 제한과 책임 음주

- 최초 진입 및 주류 콘텐츠에 `만 19세 이상만 이용할 수 있습니다`를 명확히 표시한다.
- 고정 고지: `과도한 음주는 건강에 해롭습니다. 운전 전후와 임신 중에는 음주하지 마세요.`
- 음주량 경쟁, 폭탄주, 빠르게 취하기를 장려하는 카피와 추천 로직은 사용하지 않는다.

## 8. 성공 지표

### 핵심 지표

**레시피 완성 의도율:** 추천 상세를 본 세션 중 `만들어 볼게요` 또는 즐겨찾기를 실행한 세션 비율

분석 이벤트가 안정적으로 수집되는 베타 2주 후 기준선을 만들고, 다음 4주간 20% 이상 개선을 첫 목표로 둔다.

### 퍼널 지표

| 단계  | 지표                       |  베타 목표 |
| --- | ------------------------ | -----: |
| 시작  | 홈 방문 대비 보유 술 선택 시작률      | 50% 이상 |
| 검색  | 선택 시작 대비 추천 결과 도달률       | 70% 이상 |
| 탐색  | 결과 노출 대비 상세 진입률          | 35% 이상 |
| 의도  | 상세 진입 대비 `만들어 볼게요`·즐겨찾기율 | 20% 이상 |
| 품질  | 상세에서 `추천이 도움 됨` 응답률      | 70% 이상 |
| 실패  | 제조 가능한 결과 0건 비율          | 10% 이하 |

보조 지표로 추천 결과 도달 시간, 부족 재료 구매 클릭, 7일 재방문율, 레시피 오류 신고율을 본다. 숫자는 베타 가설이며 표본 수와 유입 채널을 함께 기록해 재조정한다.

## 9. 추천 평가용 대표 시나리오

| 입력                    | 기대 상위 결과의 조건                  |
| --------------------- | ----------------------------- |
| 위스키 + 탄산수, 퇴근 후, 덜 달게 | 5분 이내의 드라이한 하이볼, 낮은 추가 구매 부담  |
| 남은 레드 와인 + 콜라         | 칼리모초 등 남은 와인 활용 레시피, 1잔 비율 제공 |
| 막걸리 + 사이다, 홈파티        | 막사 또는 과일·요구르트 변형, 탄산 취급 주의 안내 |
| 쇼츄 + 차, 반주, 무가당       | 우롱하이·녹차하이 계열, 기름진 안주와 페어링 이유  |
| 술 없음, 저도수·상큼한 맛       | 무알코올·논알코올 또는 낮은 도수 레시피를 우선 노출 |
