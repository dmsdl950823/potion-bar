## 1. 성장 가설

Potion은 “칵테일 레시피가 많다”보다 **퇴근 후 집에 있는 술을 오늘 바로 활용한다**는 메시지로 사용자를 모은다. 초기 콘텐츠는 검색 유입과 짧은 영상에 모두 재사용할 수 있도록 `상황 + 보유 술 + 쉽게 구할 재료 + 안주` 형태로 만든다.

### 핵심 메시지

- 대표: `집에 있는 술, 오늘은 맛있게.`
- 기능: `가진 술을 고르면 지금 만들 수 있는 한 잔과 안주를 추천해요.`
- 실용: `편의점 재료 1~2개면 완성.`

### 우선 유입 대상

1. 퇴근 후 혼술·반주를 즐기는 30~40대 직장인
2. 위스키·와인·막걸리를 사두고 남기는 사람
3. 주말 홈파티를 준비하는 커플·친구 모임

## 2. 채널 전략

### 검색·콘텐츠 SEO — P0

- 검색 의도를 `재료`, `상황`, `남은 술`, `안주`로 나눈다.
- 예시: `위스키 탄산수 칵테일`, `남은 와인 활용`, `막걸리 사이다 비율`, `하이볼 안주 추천`.
- 각 랜딩 페이지에 1잔 비율, 소요 시간, 예상 맛·도수, 대체재, 안주, 책임 음주 문구를 포함한다.
- 레시피 구조화 데이터와 공유용 OG 이미지를 적용한다.

### Instagram Reels·YouTube Shorts — P1

- 15~30초 포맷: 완성 컷 2초 → 보유 술·재료 → 3단계 제조 → 안주 → Potion 결과 화면.
- 시리즈: `퇴근주 5분`, `남은 술 구조대`, `편의점 한 잔`, `주말 홈바`, `덜 달게 마시기`.
- 영상마다 동일 레시피 랜딩 페이지로 연결하고 UTM으로 상세 진입과 완성 의도를 측정한다.

### 커뮤니티·뉴스레터 — P1

- 직장인·위스키·와인·홈텐딩 커뮤니티에는 정보글과 도구 사용 사례를 먼저 제공한다.
- 레시피 요청과 오류 제보를 초기 데이터 개선 루프로 연결한다.
- 커뮤니티 규정과 광고 표시 기준을 지키며 반복적인 링크 투하는 하지 않는다.

### 제휴 — P2

- 편의점·마트, 주류 브랜드, 안주 브랜드, 바틀숍과 시즌 컬렉션을 공동 제작한다.
- 제휴 콘텐츠에도 추천 기준과 광고 여부를 표시하고 일반 추천 결과를 구매 여부로 왜곡하지 않는다.

## 3. 출시 캠페인

### 준비기

- 검색 수요가 분명한 20개 핵심 레시피 랜딩 페이지 제작
- 대표 사용자 10~20명에게 보유 술 기반 결과와 재료 접근성 인터뷰
- 5개 대표 시나리오의 숏폼 원본 제작
- 이메일 또는 간단한 대기 명단보다 바로 써볼 수 있는 웹 베타를 우선 제공

### 베타 4주

- 1주차: 기존 네트워크와 관련 커뮤니티에서 소규모 사용성 검증
- 2주차: 검색 랜딩과 `퇴근주 5분` 콘텐츠 배포
- 3주차: `남은 와인·위스키·막걸리 활용` 주제 확장
- 4주차: 퍼널·0건 검색·오류 제보를 반영해 결과 품질 개선

### 채널 판단 기준

노출보다 `추천 결과 도달`, `레시피 완성 의도`, `7일 재방문`을 본다. 각 채널은 최소 표본을 모은 뒤 같은 기간·같은 랜딩 기준으로 비교한다.

## 4. 광고 원칙

- 주류 관련 법규, 매체별 연령 타기팅과 광고 정책을 집행 전에 확인한다.
- 미성년자로 보일 수 있는 모델·캐릭터, 과음·폭음·음주 운전 암시, 건강 효능 표현을 사용하지 않는다.
- 협찬·제휴·광고는 콘텐츠 첫 화면과 추천 카드에서 식별 가능하게 표시한다.
- 광고 상품이 추천 순위에 영향을 주면 `스폰서`로 분리하고 일반 추천 근거를 유지한다.
- 사용자의 음주량 증가를 광고 성과 지표로 삼지 않는다.

## 5. 수익모델 우선순위

### 1단계 — 콘텐츠 제휴와 구매 연결

- 부족 재료, 믹서, 안주 구매 링크의 제휴 수수료
- 브랜드 제공 제품을 활용한 명시적 스폰서 레시피·시즌 컬렉션
- 시작 조건: 추천 적합도와 재방문이 검증되고 광고 표시 체계가 준비된 이후

### 2단계 — B2B 콘텐츠·데이터 패키지

- 주류·믹서·안주 브랜드용 레시피 카드와 캠페인 랜딩 제작
- 바틀숍·브랜드 사이트에 제공하는 화이트라벨 조합 추천
- 익명·집계된 검색 수요 리포트는 충분한 표본과 개인정보 검토 후 제공

### 3단계 — 사용자 유료 기능

- 여러 기기 술장 동기화, 고급 컬렉션 관리, 모임용 인원수 계산, 개인 취향 리포트
- 핵심 레시피 탐색과 책임 음주 정보는 무료로 유지한다.

초기 MVP에 배너 광고를 넣지 않는다. 작은 트래픽에서는 수익이 제한적인 반면 선택 흐름과 신뢰를 해칠 가능성이 크다.
